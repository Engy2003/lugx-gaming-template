## ✨ Features
- **Fully Responsive Design:** Optimized for Desktop, Tablet, and Mobile screens.
- **Modern UI Architecture:** Utilizes advanced CSS Layouts (Flexbox & CSS Grid) for structure.
- **Custom Mobile Menu:** Features a dynamic Hamburger menu with a sleek Glassmorphism effect (backdrop-filter) and smooth transitions.
- **DOM Manipulation:** Lightweight Vanilla JavaScript used for interactive UI elements.
- **Clean Codebase:** Semantic HTML and well-structured, modular CSS variables for easy maintenance and SEO optimization.

## 🛠️ Tech Stack
- **HTML5** (Semantic structuring & Meta tags for SEO)
- **CSS3** (Custom properties, Media Queries, Flexbox, Grid, Animations)
- **Vanilla JavaScript** (ES6+, DOM Manipulation, Event Listeners)
